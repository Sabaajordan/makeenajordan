# Product images to add

Drop these image files into this folder (`src/assets/`) with the **exact** filenames below. Once they land, the site picks them up on the next build.

| Filename                     | What                                                        |
|------------------------------|-------------------------------------------------------------|
| `covim-machine.jpg`          | Covim CS100R capsule espresso machine (black, glossy)       |
| `covim-prestige.jpg`         | Covim Prestige 1 kg beans bag (black + silver)              |
| `covim-capsules.jpg`         | Covim Superba capsules group shot (5 flavors)               |
| `vending-michelangelo.jpg`   | Michelangelo Blindo vending machine (Adimac) — used as the "About" hero image, replacing the old `machine.jpg` |

## How to add them (fastest — GitHub web UI)

1. Open the repo on GitHub → `src/assets/`
2. Click **Add file → Upload files**
3. Drag the four images in (or the browse dialog), **making sure the filenames match exactly**
4. Commit to `main`
5. Netlify redeploys automatically
